Agent Cortex — Long Term Memory Service for AI Agents

An open source, self hosted memory server that lets AI agents remember things between sessions. It exposes 22 MCP tools, 49 REST endpoints and 35 CLI commands over a plain Markdown vault, with Qdrant acting as a search index that can be rebuilt at any time. Retrieval combines dense vectors with a keyword ranker written from scratch, fused through Reciprocal Rank Fusion and reordered by how useful and how often used each memory has been. Runs entirely on CPU, so nothing leaves the machine.
